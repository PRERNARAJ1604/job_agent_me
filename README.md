# Job Agent

A personal automation that finds relevant job postings and emails a daily
digest with a tailored resume for the best matches, so applying takes less
time.

Searches Indeed, LinkedIn, Naukri, company career sites, Unstop and
Internshala on a GitHub Actions schedule, ranks postings against the resume's
skills, and attaches a tailored one-page DOCX resume for each top match. It
never applies on your behalf.

**Want to run it for yourself?** Follow [SETUP.md](SETUP.md) — it covers
copying the repo, swapping in your resume and target roles, and the secrets
to set.
